# Мастерская анимаций Avalon

Шесть интерактивных концептов: три для любовников и три для Клирика +1.
Статическая страница использует оригинальные изображения из репозитория,
не требует сборки и не меняет поведение игрового клиента.

Из корня репозитория:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Открыть http://127.0.0.1:4173/tools/animation-preview/.

Нажатие на вариант сразу запускает его. Доступны попадание и два типа
промахов, повтор, сброс, двукратное замедление. При системном запросе
на уменьшение движения сразу показывается конечное состояние.
Для Клирика показана последовательность двух этапов; это демонстрация
хореографии, без ожидания настоящего выбора второй цели в партии.

## Концепты результатов миссии

http://127.0.0.1:4173/tools/animation-preview/mission.html

Три варианта: веер решений, последняя карта, печать похода.
Четыре результата, команда 2–5 участников, повтор, сброс, замедление.
Карты анонимны; для миссий с порогом 2 одна карта провала даёт успех.

Предпросмотр веера с оригинальной геометрией и изображениями стола: mission-table.html.
