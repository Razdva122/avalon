# Бесплатная проверка спроса и правки SEO-статей

14 октября 2026 года

Для правок использован [Ahrefs Free Keyword Generator](https://ahrefs.com/keyword-generator): он сработал без аккаунта, оплаты и установки расширений. Получены реальные ответы инструмента, а не числа, придуманные по формулировке запроса. Бесплатный интерфейс показывает грубые диапазоны ежемесячного спроса: `<100`, `>100`, `>1000`. Это оценки провайдера, не точные счётчики Google и не прогноз посещений сайта.

Сохранены 22 проверки исходных фраз в Google-контексте для США, России, Испании, Бразилии, Тайваня и Сингапура: 206 строк с диапазонами и пять ответов без данных. Строки включают побочные подсказки и повторения; это не 206 выбранных SEO-запросов. [CSV с наблюдениями](seo-keyword-volumes-2026-10-14.csv) удобен для фильтрации; [JSON с исходными ответами и оговорками](seo-keyword-volumes-2026-10-14.json) сохраняет доказательства и происхождение данных.

## Другие бесплатные источники

Semrush Free Keyword Search Volume Checker заблокировал доступ из текущего региона; обход не выполнялся. AltoRank сообщил, что источник DataForSEO временно недоступен. Документированный анонимный seodata.dev API вернул 403. Это ошибки доступа, а не отсутствие спроса.

Keyword Tool Guest MCP вернул два числовых англоязычных значения, но не раскрыл географию именно метрики, дату кеша и сеть. Они сохранены отдельно как `unverified_metric_geography` и не использованы для выбора приоритетов. Нативные RU/ES/PT/CN/TW запросы не получили числовых метрик. Google Trends не использован как абсолютная частотность; его индекс нельзя назвать числом поисков.

## Как повторить бесплатно

1. Открыть [генератор Ahrefs](https://ahrefs.com/keyword-generator), выбрать страну и ввести исходную фразу.
2. Сохранить видимые Keyword/Volume/Updated вместе со страной, URL и датой; не раскрывать платную часть.
3. Сравнивать только релевантные игры и формулировки в одном рынке и инструменте. При одинаковом диапазоне выбирать по поисковой задаче, без выдуманной разницы объёмов.
4. Для рынка без данных сохранить ограничение. После публикации проверять реальные показы и клики каждой статьи в Search Console по стране; они измеряют результат сайта, а не общий размер рынка.
