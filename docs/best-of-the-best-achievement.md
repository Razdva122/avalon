# «Лучший из лучших»

Открытое достижение `best_of_the_best`: после завершения рейтинговой игры TrueSkill `mu >= 6800` и **минимум 10 рейтинговых игр с последнего сброса**, включая текущую. До первого сброса считаются игры с начала истории. Награда — стикер `cleric-best` на основе клирика и предоставленного референса Макконахи. Достижение и стикер не отзываются при снижении или сбросе рейтинга.

`gamesCount` остаётся общим числом игр. Новый `gamesSinceReset` увеличивается вместе с рейтингом и становится нулём при успешном сбросе. Значение сохраняется также в результате матча: повторная обработка выдаёт награду по состоянию именно того матча, даже если игрок уже сбросил рейтинг. Игры без начисления рейтинга не учитываются.

## Историческая выдача

Миграция `2026-09-28-best-of-the-best-v1` запускается автоматически до обработчиков игр. Она восстанавливает счётчик и выдаёт достижение за первый подходящий матч, включая достижения **до последующих сбросов**. Повторный запуск не дублирует награды, не меняет даты уже выданных наград и не перезаписывает инициализированные счётчики.

Сохранённые незавершённые операции старой версии также дополняются счётчиком до возобновления обработки. Учтены частично записанные рейтинги игроков и уже сохранённый результат матча.

История матчей читается по `playedAt, _id`. В старых данных нет полного журнала сбросов: границы восстанавливаются по возвращению исходных значений к `mu=6000, sigma=1500` и по сохранённому `lastResetAt`. Несовпадение исходного рейтинга с результатом предыдущего матча без сигнатуры сброса считается разрывом: для безопасности отсчёт подтверждённых игр начинается заново. Это может недосчитать игры при повреждённой истории, но не переносит игры через неизвестный сброс. Новые результаты содержат явное `gamesSinceReset`.

Отдельный предварительный расчёт (только чтение):

```sh
cd packages/backend
NODE_ENV=development npx ts-node src/scripts/backfillBestOfTheBest.ts
```

Для применения только этой миграции добавьте `--apply`. На время отдельного применения остановите обработчики рейтинга. При обычном запуске нового backend порядок обеспечивает механизм миграций. Команда использует штатные `.env` и выводит только агрегированные числа; никаких пользовательских идентификаторов.

На странице глобальной статистики знаменатель, как и у других достижений, — все игравшие пользователи. Он отличается от выборки игроков с минимум 10 играми, использованной при подборе порога.
