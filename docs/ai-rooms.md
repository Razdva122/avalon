# AI-комната Avalon

Первый эксперимент: семь ботов Alice, Ben, Clara, Daniel, Emma, Felix и Grace
обсуждают игру на английском, обращаясь друг к другу по номерам 1–7. Номера совпадают с индексами на доске (порядок мест может меняться). Роли: Мерлин, Персиваль, два слуги, Мордред,
Моргана и приспешник; включена Леди Озера. Имена не связаны с ролями.
Зрители видят обычную доску и чат. Сообщения зрителей пока не передаются ботам.
Человеческие места — следующий этап. AI-партии не начисляют рейтинг и достижения.

## Настройка

В `packages/backend/.env.local` (не коммитить, права 600) или окружении сервера:

```dotenv
AI_ROOMS_ENABLED=true
YANDEX_API_KEY=<секретный ключ>
YANDEX_FOLDER_ID=<каталог>
AI_ROOM_ADMIN_LOGINS=razdva
AI_TOTAL_BUDGET_RUB=500
AI_MATCH_BUDGET_RUB=50
```

Модель зафиксирована: `qwen3.6-35b-a3b` через Yandex Chat Completions,
`reasoning_effort=none`, строгая JSON-схема, максимум 192 выходных токена для речи и 32 для действий.
Ключ используется только backend. Новых зависимостей нет.

Запуск для разработки при доступной MongoDB:

```sh
NODE_ENV=development npm run start --workspace=packages/backend
NODE_ENV=development npm run serve --workspace=packages/ui -- --host 127.0.0.1 --port 8080
```

Открыть http://localhost:8080, войти под `razdva`, нажать AI Avalon в лобби,
затем Start в комнате. Другие пользователи могут смотреть. Запуск и остановка
проверяются сервером по логину текущего авторизованного аккаунта.
Одновременно разрешена одна активная AI-комната; автоматического перезапуска нет.

## Ограничения и хранение

500 рублей — общий накопительный потолок, 50 рублей — потолок партии.
Настройки допускают только уменьшение этих значений. Перед каждым запросом
MongoDB атомарно резервирует консервативную оценку стоимости. После ответа
резерв сверяется с usage; при неоднозначном сетевом сбое остаётся зарезервированным.
Стоимость в панели включает такие резервы и не является выпиской провайдера.
Тариф в коде: 0,20 руб./1000 входных и 0,30 руб./1000 выходных токенов с НДС;
перед сменой модели или тарифа нужно обновить расчёт и проверить его.

Регистр расходов `ai_experiment_budget` переживает перезапуск и не обнуляется
автоматически. Это лимит приложения, он не ограничивает прочие расходы Yandex.
Публичные снимки партий лежат отдельно в `ai_room_replays`, доступны по URL комнаты.
После перезапуска незаконченная партия становится остановленной; возобновления нет.
При трёх последовательных ошибках, 350 запросах или превышении лимита — пауза.
Для новой попытки остановить текущую комнату и создать новую. Stop отменяет
текущий запрос и запрещает последующие; провайдер может успеть учесть отменённый запрос.

Каждый бот получает только своё видимое состояние, последние семь реплик ботов
и допустимые действия. Сервер проверяет выбор и применяет его обычным движком.
Корректный формат не гарантирует разумной стратегии: качество обсуждения экспериментальное.

## Проверка

`npm run test --workspace=packages/backend -- --runInBand`
проверяет движок, полный цикл AI-партии с подставной моделью, отмену,
формат ответов, права управления и атомарные ограничения расходов.
`npm run build --workspace=packages/ui` проверяет сборку и существующие UI-проверки.

Проверка 2026-09-21: живая партия `0f412f06-825b-4c9a-b3da-9f77e3d89fd6`
завершилась победой зла после трёх проваленных миссий. 45 публичных сообщений,
0 резервных действий, учтено 37,7799 рубля за эту партию. Предыдущие короткие
диагностические запросы оплачиваются отдельно и также включены в общий регистр.
Проверено отображение при 1440×1000 и 390×844, ошибок JavaScript не обнаружено.
Боты говорят по-английски, но иногда путают правила и раскрывают роли; качество
стратегии требует дальнейшей настройки. Production не обновлялся.

## Обновление обсуждения

В новых комнатах включён `displayIndex`. В запросах вместо имён используются
номера мест, текущий состав команды, номер и размер миссии, порог провала,
свой игрок и результат. Модель получает краткую памятку правил и стратегии:
отличие голосования от миссии, риск злого участника, пятое предложение,
видимость ролей, скрытые карты и правила Леди Озера.

Объявление проверки теперь формируется сервером из того же выбора Good/Evil,
который записывается в историю. Модель может соврать о фактической проверке,
но текст объявления и поле announced больше не выбираются независимо.
После конца игры каждый бот получает раскрытые роли и историю и пишет один
`Post-game:` вывод о результате своей стороны, решающем событии и уроке.
Эти семь дополнительных запросов входят в общие лимиты; остановка, ошибки API
или исчерпание бюджета могут прервать итоговый круг. Старые записи не переписываются.
Наличие правил в запросе не гарантирует понимания: модель может ошибаться,
и качество стратегии следует оценивать по реальным партиям.

## Экономный режим

Сервер ограничивает новые партии 50 рублями, даже если в окружении осталось
старое значение 100. Общий накопительный регистр не сбрасывается.
В модель передаётся компактная проекция: номера и видимые роли, текущая команда,
итоги завершённых миссий и собственные карты, последние четыре голосования,
объявления проверок с доступной игроку истиной и семь реплик до 240 символов.
Полное состояние и внутренние ID не передаются. Это уменьшает расходы и путаницу
между номером места и ID. Старые обсуждения и более ранние голосования модель
может забывать; полный чат и история по-прежнему сохраняются для зрителей.

На предложение остаются один круг обсуждения: шесть игроков сразу возвращают реплику и голос,
лидер голосует последним. Состав команды после начала круга не меняется,
ранние выступающие не пересматривают голос после поздних реплик. Поэтому
не нужны семь отдельных запросов голосования. Пятое предложение отправляется
автоматически после выбора лидера, без платного круга голосования. Действие без выбора (например,
карта Success у доброго игрока) выполняется без API. Обычная реплика ограничена
240 символами, итог — 400; модель получает максимум 192 токена для речи и
32 для действия. Обращения — обычные числа, например “I think 1 and 3 are good”.

Пользователь подтвердил приемлемый предел 20 рублей за полную партию,
включая семь итоговых сообщений. Промежуточная проверка с пределом 10 рублей
и ещё раздельными голосованиями приостановилась после 8,4969 рубля (остатка
не хватило на консервативный резерв); это не цена завершённой партии.

Последнее решение пользователя: оставить Qwen3.6-35b-a3b и поднять предел
до 50 рублей за партию, включая итоги. Alice Flash не использовалась.
Кешированные входные токены учитываются по 0,05 руб./1000 только если API
явно вернул корректный cached_tokens; без этих данных вход учитывается
полностью по 0,20 руб./1000. Резерв по-прежнему считается без скидки кеша.
Для одной и той же завершённой партии компактный контекст сократился с
11 260 до 2 879 байт (на 74%, без системной инструкции).

После каждой публичной реплики бота — пауза 10 секунд. Она применяется также
к объявлению Леди и каждому итоговому выводу, не расходует токены и немедленно
прерывается кнопкой Stop. Генерация следующего ответа может увеличить интервал.
Скрытые игровые действия без сообщений не получают дополнительной задержки.

Список лобби при запуске восстанавливается из обычных игр и `ai_room_replays`.
Записи объединяются по ID, сортируются по времени создания и сохраняют отметку AI;
подключённым зрителям отправляется обновлённый список после загрузки архива.
