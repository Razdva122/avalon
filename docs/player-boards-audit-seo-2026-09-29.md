## SEO

Новые страницы:

- `/community/players/` — поиск компании, анкеты отдельных игроков.
- `/community/groups/` — группы, ищущие игроков.
- Те же страницы на русском, испанском, португальском, упрощённом и традиционном китайском.

Сохраняется `/community/` с каталогом серверов и ссылками на обе доски.

Сделано:

- Отдельные title, description и H1 для двух поисковых намерений на шести языках.
- Статический HTML с объяснением поиска команды, публикации, условий набора и срока активности. Контент доступен без JavaScript.
- Локализованные ссылки между досками, сообществом, правилами, ролями и игрой.
- Canonical и hreflang, Open Graph и Twitter-метаданные через существующую систему маршрутов.
- Двенадцать новых канонических адресов в sitemap; языковые фильтры не создают индексируемых дублей URL.
- Видимые хлебные крошки и согласованный BreadcrumbList; WebPage с типом коллекции и связью с игрой.
- JSON API получает `X-Robots-Tag: noindex`. HTML-страницы доступны для индексации.
- Моки, приватное состояние аккаунта и формы не попадают в сгенерированный HTML. Объявления загружаются из API при открытии страницы; отдельные постоянные страницы объявлений не создавались, чтобы не размножать краткоживущие страницы контактов.

## Проверка

- 210 UI-тестов, включая сохранение черновика при фильтрации и защиту от устаревших ответов при смене аккаунта.
- 79 backend-тестов объявлений с временной MongoDB: публикация, редактирование, ограничения прав, 7-дневный cooldown, гонки, скрытие, повторная активация, истечение ровно через 30 дней, жалобы/модерация, свой язык, расписание, URL и noindex API.
- Полный браузерный сценарий с перехваченным API: создание обеих разновидностей, неверный контакт, ошибка сохранения и повтор, сохранение черновика при фильтре, редактирование, отмена, скрытие, cooldown, активация, bump, запрет набора до первой игры, название группы и приглашение, мобильная ширина, reload/Back/Home.
- Жалоба проверяется с перехватом отправки, без записи в базу.
- Production HTML: новые страницы во всех шести языках, ровно один H1, метаданные, ссылки, sitemap и BreadcrumbList; никаких DEMO-контактов или форм.
- Production-проверки SEO, навигации, размеров ресурсов, изображений, восстановления пароля, поддержки, запуска и Web Vitals. Проверка HTTP через реальную конфигурацию Nginx.
- Всего пререндерится 204 страницы. Лимит critical CSS 8 KiB gzip не увеличен.

## После публикации

Нужна выкладка текущей сборки, затем проверка URL в Search Console и отправка sitemap. Доступ к Search Console в этой задаче не предоставлялся. Поисковые позиции и трафик не гарантируются метаданными: индексирование и результат оцениваются после публикации по показам, переходам и запросам. Регулярно проверять, что доски содержат актуальные объявления.

Основания: [Google — обнаруживаемые ссылки](https://developers.google.com/search/docs/crawling-indexing/links-crawlable), [JavaScript SEO](https://developers.google.com/search/docs/crawling-indexing/javascript/javascript-seo-basics), [canonical](https://developers.google.com/search/docs/crawling-indexing/consolidate-duplicate-urls).

## Исправления после проверки пользователем

Предыдущий браузерный сценарий использовал подменённый API и полные актуальные DTO. Он не покрывал сохранение уже существующей локальной анкеты с отсутствующим `otherLanguage` (и `scheduleEnabled` у группы). Из-за этого прежний вывод о полноте проверки редактирования был слишком широким.

- Подготовка черновика теперь задаёт пустой дополнительный язык и выключенное расписание, если эти необязательные значения отсутствуют. Проверена валидация данных обеих существующих локальных анкет без изменения базы.
- Скрытое объявление с неистёкшим сроком можно активировать сразу: прежние `bumpedAt` и `expiresAt` сохраняются. Это не поднимает объявление и не обходит семидневный cooldown. Истёкшая анкета при активации получает новые 30 дней.
- Кнопка «Активировать объявление» выделена цветом; подсказка о cooldown отображается только у активных анкет.
- Добавлены HTTP/MongoDB-регрессии для редактирования неполной сохранённой записи и конкурентной активации обеих досок до окончания cooldown, а также проверки настоящих Vue-компонентов формы и карточки. 214 UI-тестов и 81 backend-тест прошли.
