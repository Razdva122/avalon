# Локальный эксперимент: боты Avalon через Codex / ChatGPT

1 октября 2026. Исследовательский запуск, не интеграция в production.

**Подключение подтверждено; партия не завершена.** Семь существующих ботов играли через локальный Codex CLI 0.159.2 с текущей авторизацией ChatGPT. `codex login status` показал ChatGPT; переменные `CODEX_API_KEY` и `OPENAI_API_KEY` отсутствовали. API Яндекса, MongoDB и работающий сервер не использовались.

Использован настоящий `BotRoom` и существующий `decisionPipeline`: приватные решения, ограниченная память каждого игрока, отдельная публичная речь, проверка выбора, Леди Озера и штатная пауза. Каждый запрос запускался в отдельной ephemeral-сессии в пустой рабочей папке. Инструменты запрещены инструкцией; эксперимент прерывает процесс при событии вызова shell/MCP/search/file-change. Это контроль эксперимента, не полноценная изоляция процесса. Выбрана низкая глубина рассуждений; ID модели по умолчанию CLI не записан, поэтому результат нельзя приписывать конкретной модели.

## Причина остановки и контроль исправления

В ответе №108 поле `evidence[0].source` имело 169 символов при максимуме 160 в `parseDecisionReply`. Экспериментальная JSON-схема не задавала `maxLength`, хотя текстовые инструкции задавали лимит. Backend корректно отклонил ответ и поставил игру на техническую паузу до применения хода.

В схему прототипа добавлен `source.maxLength: 160`. Отдельный запрос №109 на той же сохранённой позиции прошёл штатный парсер, сохранив выбор `reject`. Он занял 14,73 с и использовал 18 841 входной / 224 выходных токена. Этот контроль проверил только исправление формата: партия после него не возобновлялась. Полный прогон с исправленной схемой ещё не проведён.

## Наблюдения по стратегии

- Бот 1 (слуга) правильно определил зло в 2 после единственного Fail рядом со своей картой Success.
- Бот 1 затем многократно отклонял чистую команду 3,4,5, предпочитая включение себя. На четвёртом предложении это позволило злому пятому лидеру 6 принудительно провести 3,4,6 и провалить вторую миссию.
- Злой бот 7 проверил союзника 6 и объявил Good вопреки истинному Evil. Последующие добрые боты не считали заявление достоверной проверкой без доверия к его автору.
- Публичные реплики формировались из существующей публичной проекции, отдельно от приватных ролей и рассуждений.

Одна незавершённая партия не позволяет сравнить силу моделей. Подтверждена возможность тестового локального запуска через подписку; выявлены накладные расходы и несовпадение схемы с парсером.

## Артефакты и повторение

- `summary.json` — краткие результаты.
- `result.json` — состояние на паузе, история миссий и публичный чат.
- `calls.jsonl` — приватные игровые контексты и ответы, включая исходный сбой и отдельное исправление; содержит раскрытые роли тестовой партии.
- `repair-result.json` — результат проверки формата.
- `run.cjs` — временный исследовательский прототип с исправленным лимитом source. Не production-провайдер; не меняет UI или конфигурацию серверных ботов.

Для повторения требуется установленный и авторизованный Codex CLI, Node и зависимости репозитория:

```sh
node docs/ai-evaluations/2026-10-01-codex/run.cjs
```

Повторный запуск начинает новую случайную партию, расходует лимиты аккаунта и перезаписывает выходные файлы в этой папке — сначала сохраните текущие результаты отдельно. Ограничения прототипа: 350 генераций / 30 минут, 180 секунд на запрос. Авторизация повторно не настраивается; секреты не копируются.

Проверка существующего игрового пути: 48 тестов прошли в `room.test.ts` и `pipeline.test.ts`. Рабочий backend и UI не изменены.
