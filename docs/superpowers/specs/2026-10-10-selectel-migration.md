# Avalon: требования к переезду в Selectel

Дата: 10 октября 2026. Статус: предложение к исполнению; инфраструктура этим документом не изменяется.

## Цель и границы

Снизить регулярную стоимость backend, MongoDB и голоса после отмены бонуса Yandex Cloud. Пользователь выбрал самый дешёвый подходящий вариант Selectel. Перенести действующий сервис с проверкой данных, голоса, почты и возможностью отката.

Целевой продукт — фиксированный **VDS 4-8-80: 4 vCPU, 8 ГБ RAM, 80 ГБ диска, 1 100 ₽/месяц по публичному тарифу**. Это не конфигурируемый продукт «Облачные серверы». Перед заказом проверить итоговую цену в кабинете, налог и длительность расчётного месяца.

Основной вариант — один VDS. Совместное использование TCP 443 сайтом и TURN сначала проверяется на тестовом стенде. Если проверка не проходит, запасной вариант — отдельный **VDS 1-2-25 за 250 ₽/месяц** для LiveKit; сумма двух серверов 1 350 ₽/месяц. Не отключать TURN ради достижения цены 1 100 ₽.

## Global Constraints

- В каждый момент только один production-backend имеет право записывать в рабочую базу.
- Не переносить незавершённые партии: состояние игр находится в памяти backend.
- Не менять версию MongoDB одновременно с переездом.
- Не подключать тестовый backend к production LiveKit: запуск backend очищает комнаты.
- Сохранить ключи сессий, шифрования почты, почтовых событий и рабочие данные пользователей.
- MongoDB, LiveKit API и управляющие voice-endpoint не доступны из публичного интернета.
- TURN/TLS на TCP 443 и доступность из проблемных пользовательских сетей — обязательные условия запуска.
- Codex worker остаётся на существующем удалённом хосте.
- Object Storage с изображениями, Postbox и обработчик почтовых событий остаются в Yandex Cloud.
- Резервная копия должна храниться вне VDS; работоспособность подтверждается восстановлением.
- После появления новых записей в Selectel откат требует переноса этих записей обратно; одной смены DNS недостаточно.

## Исходные данные и неопределённости

По предыдущему аудиту в этой беседе: backend VM 4 vCPU / 8 ГБ / 250 ГБ; voice VM 2 vCPU / 4 ГБ / 20 ГБ. Оценка без бонуса: 6 525,73 + 3 212,29 = 9 738,02 ₽ за 720 часов, только эти две VM. Эти цифры не являются повторным измерением или свежим счётом от 10 октября.

На основном сервере использовалось около 2,9 ГБ RAM; MongoDB — около 1,9 ГБ, backend — около 740 МиБ. Из примерно 186 ГБ занятого диска около 160,7 ГБ приходилось на Docker images, рабочая БД занимала около 1,4 ГБ. Голос потреблял существенно меньше выделенных ресурсов. Перед заказом повторить измерения и проверить новые данные/тома.

8 ГБ — рабочая начальная гипотеза с запасом на обслуживание; 4 ГБ не принимается как исходная конфигурация. Сборки делать вне production. 80 ГБ подтверждаются пробным восстановлением, а не сравнением размеров исходного виртуального диска.

У дешёвого VDS один IPv4 без возможности добавить второй, отсутствуют приватная сеть и автоматические резервные копии; SMTP 25/465/587 ограничен. В коде отправитель использует 465. Поэтому нужны отдельная проверка схемы голоса и переход почты на HTTPS API.

Selectel размещает этот продукт в РФ. Проверить новый IP из Украины до переезда; положительный результат из одной сети не доказывает доступность у всех пользователей.

## Критерии приёмки

1. Подтверждены итоговый тариф, выбранная схема голоса и ежемесячная стоимость внешних бэкапов.
2. Есть воспроизводимый deploy с закреплёнными образами, восстановлением после reboot и автоматическим обновлением сертификатов.
3. Проверены регистрация/вход, старая учётная запись, история игр, новая партия, чат, изображения, голос, восстановление пароля и используемые интеграции.
4. Проверен голос через обычный UDP и принудительный TURN/TLS 443, в том числе из проблемной сети.
5. Проверено восстановление внешнего бэкапа; зафиксированы фактические время переноса и время отката.
6. После переключения нет двух активных backend, потерянных записей и необъяснённых расхождений данных.
7. Наблюдение 48–72 часа не выявило блокирующих ошибок; старые ресурсы удаляются только после дополнительной проверки восстановления.
