# Lobby AI launch implementation plan

**Goal:** Launch the existing lobby with strong bots, preserving its ID and chat.

**Approved design:** The host selects total seats 5–8. At least one human and one bot are required. Five/six-seat tables allow any remaining bot seats; seven/eight-seat tables allow two bots without host Premium and any remaining seats with host Premium. Fixed AI rules and text-chat limitations are disclosed before launch.

**Architecture:** Keep ordinary rooms unchanged until launch. Query host-specific availability with `getLobbyAiAccess(roomID, callback)`. Launch with `startLobbyAiRoom(roomID, { playerCount, language, humanPlayerIDs }, callback)`. Reuse AI resource allocation and BotRoom, adopting existing room identity, creation time and chat. Compare the confirmed roster before and after asynchronous checks. Failed preparation leaves the original room intact and releases its lease.

**Tech stack:** TypeScript, Vue/Vuetify, Socket.IO, Jest, existing Node UI tests. No new dependencies.
