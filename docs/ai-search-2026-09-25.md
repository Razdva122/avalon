## 2. Изменение главной

Добавлен видимый текстовый раздел после списка комнат: три шага запуска и ответы о стоимости, аккаунтах, устройствах, общении, ролях и расширениях. Все шесть языков используют существующую систему переводов. Ссылки на правила, роли и расширения сохраняют язык страницы. Текст должен присутствовать в пререндеренном HTML до подключения к backend.

Факты проверены по Lobby.vue, StartPanel.vue, обработчикам авторизованных событий backend, Chat.vue и существующим описаниям возможностей. Вход требуется создателю и участникам; вход в комнату для просмотра не равнозначен участию в партии. Голосовой разговор предлагается организовать отдельно. Бесплатность относится к обычной игре с друзьями; у premium и AI отдельные условия.

Изменения локальные: дата публикации ещё не зафиксирована. После выкладки проверить HTTP/HTML и live URL test в Search Console. Повторная отправка неизменённого sitemap сейчас не требуется.

Проверено локально: `npm run build:ui` завершился с кодом 0, включая 65 UI-тестов и штатные SEO, structured-data, навигационные, bundle и browser-проверки. Дополнительно Chrome без JavaScript проверил наличие всех трёх шагов, четырёх ответов, правильных локализованных ссылок и отсутствие горизонтального переполнения на всех шести главных страницах при ширине 390 и 1280 px. Русская мобильная версия просмотрена визуально. Форматирование и `git diff --check` проходят. Проверка кода не выявила функциональных замечаний.

Штатный сканер иконок учитывает совпадения слов в текстах переводов; после добавления текста потребовалась регенерация набора. Добавлено шесть глифов, размер шрифта вырос с 13 128 до 13 408 байт. Новых зависимостей приложения нет. Для пререндеринга сборка запускалась с доступом к локальному HTTP-порту и установленному Chrome: песочница запрещала открытие порта.
