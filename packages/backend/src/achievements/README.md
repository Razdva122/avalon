# Система достижений Avalon

[Documentation index](../../../../docs/README.md)

Эта директория содержит реализацию системы достижений для игры Avalon.

## Структура

- `index.ts` - основной сервис для работы с достижениями и менеджер достижений
- `handlers.ts` - обработчики событий для достижений
- `data.ts` - данные для инициализации достижений

## Модели данных

Модели данных для достижений определены в `packages/types/stats/achievements.ts`:

- `Achievement` - модель достижения (содержит только id, type, requirement и metadata)
- `UserAchievement` - модель достижения пользователя (содержит прогресс и состояние)
- `AchievementStats` - модель статистики достижений (содержит статистику по каждому достижению)

Тексты и иконки для достижений хранятся на фронтенде, что упрощает локализацию и изменение визуального представления.

## Константы

Константы для идентификаторов достижений определены в `packages/types/stats/achievements-constants.ts`.

## Инициализация

Встроенный каталог проверяется при каждом старте backend до открытия HTTP-порта.
Отсутствующие записи восстанавливаются без перезаписи существующих требований;
некорректное требование останавливает запуск. Реализация — `ensureAchievementCatalog`
в `packages/backend/src/db/migrations/index.ts`.

Старый npm-script `init-achievements` ссылается на отсутствующий
`src/scripts/initAchievements.ts`; используйте штатную startup-инициализацию.

## Интеграция с игрой

При завершении игры обработчик сохранённого результата в `scripts/game-results.ts`
вызывает обработку достижений через очередь операций рейтинга. Последовательность
игры защищает прогресс от повторного начисления. События `playerReachTop1`
и `playerRevealSecret` обрабатываются через `eventBus`.

## Достижения

### Открытые достижения

1. **Защитник Камелота** - Выиграть 10 игр на стороне сил света
2. **Агент Мордреда** - Выиграть 10 игр на стороне сил тьмы
3. **Мастер на все руки** - Выиграть на каждой роле из стандартного набора: Мерлин, Персиваль, Мордред, Моргана, Оберон, Сервант, Миньон
4. **Универсальный солдат** - Выиграть игру на 5, 6, 7, 8, 9, 10 человек
5. **Охотник на волшебников** - Убить Мерлина 5 раз
6. **Легенда Авалона** — награда через обработчик первого места в рейтинге
7. **Охотник за секретами** — открытое достижение `secret_hunter`
8. **Лучший из лучших** — рейтинг не ниже 6800 после минимум 10 рейтинговых игр с последнего сброса; [правила и историческая выдача](../../../../docs/best-of-the-best-achievement.md)

### Скрытые достижения

1. **Агент под прикрытием** - Будучи Мерлином выбрать Моргану дважды на миссию и после этого выиграть игру
2. **Что за бесполезная роль** - 5 раз на Клирике отправить первый поход
3. **Все еще достоин** - Использовать Экскалибур в 5-ом походе и выиграть игру на мирной роле
4. **Сыщик** - Будучи Мерлином проверить лояльность Мордреда при помощи Леди Озера
5. **Ошибки случаются** - Нажать фейл всеми мафиями в походе (в походе только мафии)
6. **Серийный убийца** - Убить хотя бы раз Мерлина, Клирика и любовников
7. **Неправильный выбор** - Будучи Морганой попасть в три провальных похода
8. **Телохранитель** - Получить выстрел будучи Персивалем
9. **Провидец** - Будучи Сервантом собрать все походы без мафии (минимум 3 раза за игру (5-6 игроков) / 2 раза (7+ игроков))

## Сохранение и уведомления

Прогресс обновляется атомарно с уникальным ключом `(userID, achievementID)`.
Ключи состояния и последовательность игры защищают от повторного начисления.
Завершённое достижение сохраняется. Сервис отправляет `achievementProgress`
и `achievementUnlocked` в приватный канал `user:<id>`. UI отображает прогресс,
глобальную статистику и связанные unlocks; это уже реализованные возможности.
AI-партии не начисляют человеческие достижения.

Каталог и требования: `data.ts`; условия: `handlers.ts`;
общие ID и пороги: `packages/types/stats/achievements-constants.ts`.
Эти исходники определяют условия при изменении игровых правил.

## Проверки

```sh
npm run test --workspace=packages/backend -- --runInBand src/achievements
```

Дополнительные тесты рейтингов и миграций проверяют выдачу наград после
завершения игры, повторы и инициализацию каталога.
